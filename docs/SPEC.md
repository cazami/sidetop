# Sidetop 仕様書

> Sidetop – Horizontal Scrolling Desktop
> Windows のデスクトップを、マウスホイールで左右にスクロールできるようにする Windhawk モッド。

この文書は、Claude Code に実装を依頼するための仕様書です。実装はマイルストーン順に進め、各マイルストーンの終わりに動作確認の手順と結果を報告してください。

---

## 1. 目的とコンセプト

- デスクトップを右方向に拡張し、マウスホイールだけで横に移動できるようにする。
- **純正と見分けがつかない操作感**を最優先する。アイコンの見た目、右クリックメニュー、ドラッグ&ドロップ、選択などは Explorer 純正のまま動くこと。
- 移動は**滑らか**であること。連続スクロール（既定）と、ページ単位の離散スクロールを設定で切り替えられる。

## 2. 対象環境と配布形態

| 項目 | 内容 |
|---|---|
| 形態 | Windhawk モッド（1ファイル `sidetop.wh.cpp`、C++） |
| モッドID | `sidetop` |
| 対象プロセス | `explorer.exe` |
| 優先OS | **Windows 10（22H2）を先に正式対応**。Windows 11 は v1.0 以降に対応 |
| 配布 | まずソース（GitHub / Gist）で配布し、その後 Windhawk 公式カタログへ申請 |

- Windhawk カタログの投稿ルールに従い、コードは1ファイルに収めること。
- 設定は Windhawk の設定機能（`// ==WindhawkModSettings==`）で提供する。
- 投稿時のテンプレートでは、Claude による作成であることを申告する。

## 3. 基本仕様

### 3.1 デスクトップの拡張

- モッドを入れると、デスクトップが**右側に拡張**される。
- **左端には限界があり、元の配置（ホーム）で止まる**。ホームより左には行けない。
- **右端**は固定で、既定は**ホーム＋1画面分（デスクトップが2画面分の幅になる）**。何もない空間へ無限に進んで迷子にならないようにするため。また幅が決まっていると、壁紙（横長壁紙・パララックス）の扱いが簡単になる。（2026-10-28 変更。当初は「一番右にあるアイコン＋1画面分」）

### 3.2 操作

| 操作 | 動作 |
|---|---|
| ホイール上 | 左へ移動 |
| ホイール下 | 右へ移動 |
| ホイールのチルト、タッチパッドの横2本指スワイプ | 対応する方向へ移動 |
| 中ボタンドラッグ | 掴んで左右に移動 |
| 空き部分のダブルクリック | ホームへ戻る（設定でショートカットキーに変更可） |
| Ctrl+ホイール | **純正の動作（アイコンサイズ変更）のまま残す** |

- ホイールは、カーソルがデスクトップ上にあり、手前にウィンドウがないときに有効。**アイコンの上でホイールを回しても移動する**。
- Ctrl+ドラッグはデスクトップ純正の操作（コピー、選択の追加）と衝突するため使わない。

### 3.3 スクロールの感触

- 移動は常にアニメーションで滑らかに行う。慣性あり。
- **連続モード（既定）**: ホイール量に応じてなめらかに流れる。
- **離散モード**: 1ページ（1画面幅）単位で移動し、止めたときにページ境界へ吸着する。
- 速度と慣性の強さは設定で変更できる。

### 3.4 アイコンの扱い

- アイコンをドラッグして画面の左右端で少し止めると、**その方向へ自動スクロール**し、別のページへ移せる。
- **新しく増えたアイコン**（ダウンロードなど）は、**今見ている画面**の空き位置に出す。
- アイコンの配置と、最後に見ていた位置は**再起動後も保持**する。

### 3.5 壁紙

| 設定 | 動作 |
|---|---|
| 固定（既定） | 壁紙は動かない |
| パララックス | アイコンより遅れて少し動く |
| 横長壁紙 | 横長の画像を、スクロールに合わせて一緒に流す |

- 壁紙の描画方法は、v0.1 の技術調査の結果を見て決める（6章）。

### 3.6 位置インジケーター

- スクロール中だけ画面下部に細いバーを表示し、止まったら短時間でフェードアウトする。
- 装飾は最小限にし、Windows 純正の雰囲気を崩さないこと。

### 3.7 マルチモニター

- モニターごとに個別にスクロールする。

## 4. 安全策（必須）

- **アンインストール・無効化時の復元**: モッドの終了処理（`Wh_ModUninit`）で、すべてのアイコンを画面内に戻す。ホーム以外のページにあるアイコンは、ホーム画面の空き位置へ移す。ファイルが消えたように見える事故を絶対に起こさないこと。
- **「アイコンの自動整列」がオンの場合**: 配置が崩れるため、モッドは動作を止め、ログで警告する（設定の説明欄にも注意書きを入れる）。
- **Explorer の再起動・クラッシュ時**: 再読み込み後に保存済みの状態から復元できること。
- **開発中の注意**: 実装やテストの前に、デスクトップのアイコン配置をバックアップする手順を必ず案内すること。

## 5. 設定項目（Windhawk 設定）

| 項目 | 既定値 |
|---|---|
| スクロールモード（連続 / 離散） | 連続 |
| スクロール速度 | 標準 |
| 慣性の強さ | 標準 |
| ホームへ戻る操作（ダブルクリック / ショートカットキー / なし） | ダブルクリック |
| 壁紙（固定 / パララックス / 横長） | 固定 |
| 横長壁紙の画像パス | 空 |
| 位置インジケーターの表示 | オン |
| 自動スクロールまでの待ち時間 | 0.5秒前後 |

## 6. 技術方針と調査事項

### 6.1 前提

- デスクトップのアイコン層は、Explorer 内の `Progman` → `SHELLDLL_DefView` → `SysListView32` というウィンドウ構成になっている（Windows 10）。
- モッドは `explorer.exe` 内で動くため、このウィンドウをサブクラス化してホイールやマウス入力を受け取れる見込み。

### 6.2 v0.1 で検証すること

スクロールの実現方法として、次の候補を比較し、最も滑らかで純正の挙動を壊さないものを選んでください。

1. `SysListView32` ウィンドウ自体を画面より広くして、位置をずらす
2. ListView のビュー原点やスクロール機能を使う
3. 各アイコンの座標を書き換える（`LVM_SETITEMPOSITION` など）

判断材料として、次の点を報告してください。

- アニメーション中にちらつきや遅延が出ないか
- 画面外のアイコンを Explorer が勝手に画面内へ戻さないか
- クリック、右クリックメニュー、ドラッグ&ドロップ、ラッソ選択が正常に動くか
- 配置の保存先（レジストリの `HKCU\Software\Microsoft\Windows\Shell\Bags\1\Desktop` など）に、ずれた座標が書き込まれて壊れないか
- 壁紙をスクロールさせる方法（アイコン層の背面へウィンドウを差し込む手法など）が使えるか

## 10. 発信用メモ

- デモ動画は、**横長壁紙が流れるカットを冒頭**に入れる。
- その後、ホイールで移動 → アイコンを別ページへ移す → ダブルクリックでホームへ戻る、の順で見せる。
